APRÈS LE LANCEMENT (30 secondes):

1. Ouvrez votre navigateur et allez à:
   👉 http://localhost:3000

2. Vous verrez le tableau de bord avec:
   - Statistiques en direct
   - Liste des emplois
   - Panel de gestion des agents

3. Pour accéder à l'API:
   👉 http://localhost:8000/docs

================================================================================

SI VOUS TESTEZ AVEC CURL:

Obtenir tous les emplois:
  curl http://localhost:8000/jobs

Lancer un agent (scraper):
  curl -X POST http://localhost:8000/agents/1/run

Voir les statistiques:
  curl http://localhost:8000/dashboard/stats

Mettre à jour un emploi:
  curl -X PATCH http://localhost:8000/jobs/1 \
    -H "Content-Type: application/json" \
    -d '{"status": "envoye"}'
